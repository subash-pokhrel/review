
##  Summary
- **Hybrid storage** → Needed for low-latency, compliance, phased migration, DR, edge.  
- **DataSync** → Fast, automated transfer tool.  
- **Storage Gateway** → Integration (File, Volume, Tape).  
- **AWS Storage Services** →  
  - **S3 (Object)** = unlimited, durable, low cost.  
  - **EFS (File)** = shared, scalable NFS.  
  - **EBS (Block)** = high IOPS, low-latency for EC2.  
- **Storage Types** → Object vs File vs Block (know differences).  
- **Performance & Scalability** → Always choose based on **workload** + **cost efficiency**.

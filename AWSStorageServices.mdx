##  AWS Storage Services

### 1: Object Storage (Amazon S3)
- It is a type of storage that stores unstructured data as objects (data + metadata + unique ID).
- It's durability is 99.999999999% (11 9’s).
- **Scalability**: Virtually unlimited.
- **Storage Classes**:  
    - Standard (frequent access).  
    - Standard-IA (infrequent access).  
    - One Zone-IA (single AZ, lower cost).  
    - Glacier / Deep Archive (long-term archival).  
    - Intelligent-Tiering (automated cost optimization).  

**Use Cases**:
- Backups, static websites, media storage, log archives, analytics data lakes.


---

### 2: File Storage (Amazon EFS)
- It is a storage system which fully managed **NFS** file system.
- **Scalability**: Automatically scales to petabytes.
- **Access**: Thousands of EC2 instances can mount concurrently.
- **Performance Modes**:  
    - General Purpose (low latency).  
    - Max I/O (higher throughput, higher latency).  

**Use Cases**:
- Web apps, CMS, home directories, developer environments.

---

### 3: Block Storage (Amazon EBS)
- IIt is a type of storage which does persistent **block-level storage** for EC2.
- **Performance**: Low-latency, high IOPS.  
- **Volume Types**:  
    - gp3 (general purpose, balanced).  
    - io2/io2 Block Express (high performance for databases).  
    - st1 (throughput-optimized HDD).  
    - sc1 (cold HDD, lowest cost).  

**Use Cases**:
- Relational databases, transactional systems, boot volumes, critical apps.
